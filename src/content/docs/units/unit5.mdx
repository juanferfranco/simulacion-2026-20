## Sistemas de partículas

**Alineación con el libro:** unidad 4 de [*The Nature of Code*](https://natureofcode.com/particles/)

## Propósito

Una partícula aislada puede moverse. Una relación hace posible una estructura. Una estructura que cambia puede convertirse en lenguaje.

En esta unidad estudiarás los sistemas de partículas como estructuras de elementos relacionados: vínculos, dependencias, equilibrio, tensión, organización, propagación del movimiento y transformación. El código será un medio para construir el sistema; el centro será comprender cómo sus cambios pueden comunicar.

## Actividades

### Actividad 01: referentes para la unidad

**Referente 1: Alexander Calder**

Conocerás [Alexander Calder y sus esculturas cinéticas](https://calder.org/). Observa cómo la suspensión, el peso, la dependencia y el equilibrio hacen que una variación en un elemento afecte la estructura completa. Calder será un referente conceptual para pensar relaciones y movimiento, no un estilo visual que debas imitar.

Puedes ver más adelante este [video sobre Alexander Calder](https://www.youtube.com/watch?v=VewUU7mYzTk).

**Referente 2: ForumTEDTALK**

Conocerás el proyecto [ForumTEDTALK](https://github.com/juanferfranco/ForumTEDTALK), un caso real de diseño en el que un guion de presentación se interpreta mediante un sistema visual generativo. Observa cómo las frases se traducen en cambios de comportamiento, movimiento, relaciones, densidad y composición, sin ilustrar literalmente el discurso.

También puedes recorrer [la presentación con mi propuesta de diseño](https://juanferfranco.github.io/ForumTEDTALK/).

Consulta los [insumos del cliente](https://drive.google.com/drive/folders/1DoaP6OaAYheK7p3QUW_QAkjCA0l2aVBO?usp=sharing) que utilizarás como base para el encargo.

En ambos referentes, pregunta: ¿Qué relación sostiene la estructura?, ¿Qué cambia?, ¿Cómo ese cambio produce sentido?

### Actividad 02: encargo de diseño

**Reto de diseño: una estructura que se convierte en lenguaje**

El Centro de Eventos Fórum UPB necesita una presentación visual para la charla **“Relevo generacional: la ventaja que nadie está aprovechando”**. Trabajarás con el mismo guion del cliente que utilizará todo el grupo.

Para desarrollar el encargo, consulta los [insumos del cliente](https://drive.google.com/drive/folders/1DoaP6OaAYheK7p3QUW_QAkjCA0l2aVBO?usp=sharing).

**Reto**

Diseña una presentación generativa que interprete este guion mediante una estructura dinámica de elementos relacionados y en movimiento.

Tu sistema visual deberá construir significado a través de cambios en sus relaciones, equilibrio, tensión, organización y comportamiento. La intención no es ilustrar literalmente cada frase ni decorar la presentación con partículas, sino desarrollar una gramática visual propia capaz de acompañar y transformar el discurso.

Alexander Calder es un referente conceptual para pensar la relación entre estructura, dependencia, equilibrio y movimiento, no un estilo visual que deba ser imitado.

**Tu propuesta deberá:**

* utilizar un sistema de partículas o elementos vinculados mediante relaciones estructurales;
* definir qué significan esas relaciones dentro de la propuesta y cómo cambian a lo largo del discurso;
* hacer que los cambios importantes de movimiento o estructura respondan a una intención comunicativa;
* interpretar el guion suministrado sin modificar su secuencia narrativa;
* funcionar como una presentación web en pantalla completa, diseñada para una pantalla grande, con legibilidad, composición y comportamiento adecuados para ese contexto.

**Regla de diseño**

> Ningún movimiento debería existir solamente para decorar. Todo cambio importante del sistema debe poder explicarse en términos de una relación, una transformación estructural o una intención comunicativa.

El código es un medio y puede construirse con apoyo de IA. Lo importante es que puedas comprender, intervenir, justificar y explicar el sistema que diseñaste.

### Actividad 03: presentación grupal

En la sesión mostrarás al grupo tu presentación funcionando y explicarás brevemente:

1. El concepto de su propuesta.
2. Cuál es su gramática visual.
3. Cómo utilizó las relaciones estructurales y el movimiento para interpretar el discurso.

Antes de presentar, debes tener terminada en tu bitácora la autoevaluación del proyecto. Cada criterio vale **25 puntos**:

1. **Cumplimiento del encargo:** mi presentación interpreta el guion mediante una estructura dinámica y funciona en pantalla completa.
2. **Relaciones estructurales:** puedo explicar qué relaciones existen en mi sistema, qué significan y cómo organizan sus elementos.
3. **Comportamiento y significado:** puedo relacionar los cambios de movimiento, estructura, densidad o composición con una intención comunicativa.
4. **Explicación y demostración:** puedo presentar la propuesta funcionando, explicar mis decisiones y demostrar cómo el sistema construye sentido.

> ¿Cómo puede una estructura de elementos relacionados y en movimiento convertirse en un lenguaje visual capaz de construir el significado de un discurso?
